# Legacy OBJ/CSV pose pipeline

This directory preserves the original research implementation and its outputs.
It is retained for traceability and comparison; production development belongs
in `../src/chute_pose/`.

## Contents

- `Main.py`, `PoseFinder.py`, `PoseEliminator.py`, `CylinderHandler.py`,
  `CentroidSolidAngleAnalyser.py`, and `PoseVisualizer.py`: original pipeline.
- `obj_*`, `stl_to_obj_*`, and `step_find_*`: legacy conversion helpers.
- `Pose_Plots/`: plots generated by the legacy pipeline.
- `Workpieces/`: the earlier example workpiece dataset and redundant mesh
  formats used by that pipeline.
- `Candidate_Rotations_*.zip`: archived candidate-rotation output.

The legacy code expects OBJ/convex-hull OBJ and intermediate CSV files and may
require Blender's `bpy` module. It is not exercised by the modern test suite and
is not called by `../chute-pose.ps1`.

Use the modern pipeline instead:

```powershell
cd ..
.\chute-pose.ps1 --help
```

The active workpiece directory `../Werkstücke_STL_grob/` intentionally contains
only STL calculation meshes and STEP verification models. Historical redundant
exports remain recoverable from Git history.
